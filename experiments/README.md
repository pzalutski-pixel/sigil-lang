# Experiments

Studies testing whether an AI-native language actually helps an AI write code. Each
**study** is one coding task, re-run as the toolchain evolves; the run folders inside
it are neutrally named (`run-N`) and the study's own `README.md` says **what each run
is**. The narrative tying everything together is
[The Sigil Experiment](../docs/THE-SIGIL-EXPERIMENT.md).

## Studies

- **[http-relay/](http-relay/)** — an HTTP file-relay coding task, written from
  scratch by a cold AI agent and re-run as the toolchain advanced — five runs to
  date (Jan baseline · June rigorous baseline · +hash tooling · +stdlib ·
  +bug-fix validation). Run index and per-run descriptions:
  [http-relay/README.md](http-relay/README.md).

A second study (a different task) becomes its own sibling folder here, with its own
`README.md` describing its runs.
